# 주간 계획 검토 표

지난주 업데이트와 이번 주 계획은 주차별로 분리해 월~금 5행으로 보여 준다. 기본 열 순서와 이름은 다음과 같다.

| 요일 | 계획 | 실제 작업 결과 | 업데이트안 |
|---|---|---|---|
| 금 MM/DD | [완료] 기존 업무 (0/12) | 누적 5/12 완료, 잔여 7건. 현재 기한 MM/DD | [완료-지연(MMDD)] 기존 업무 (5/12) |

- `계획`은 `local read --week`로 읽은 기존 확정 내용이다. 최신 Jira 날짜로 이 열을 덮어쓰지 않는다.
- `실제 작업 결과`는 Jira 최신 상태·실적 종료일·집계 대상 티켓을 근거로 기존 계획의 예정대로 완료/진행/지연 여부를 설명한다. 미래 날짜는 `예정 — 현재 상태 ...`로 표시하며 수행한 실적으로 쓰지 않는다.
- `업데이트안`에는 시트에 실제로 들어갈 문구·완료 예정 태그·실제 완료 취소선을 그대로 보여 준다. 변경/추가/삭제 설명은 셀 문구와 구분한다. 승인 전에는 로컬·Google·Jira를 수정하지 않는다. 가확정도 저장 승인이 아니다.
- 완료 예정일을 넘겨 미완료면 기존 예정일에 `[완료-지연(MMDD)]`, 변경 예정일에 `[완료]`를 둔다. 실제 완료 근거가 있는 줄에만 취소선을 적용한다. 집계는 날짜별 누적 실적이며 현재 완료 건수를 과거 모든 날짜에 소급하지 않는다.
- 같은 목적의 하위 기능은 부모 업무명으로 묶는다. 세부 기능명 나열 대신 사용자가 확정한 이름을 labels에 보관한다. Forgejo 이슈 일괄 정리·주석 정리 등은 `[리팩토링·버그 수정] 업무명`으로 성격을 표시한다.
- 사용자 조정은 Jira 날짜와 구분해 계획에 반영한다. 시트 일정 승인만으로 Jira 기한·상태를 바꾸지 않는다. 자료 미수령 등으로 완료일을 정하지 못한 업무는 배정한 날에 진행 문구만 넣는다.
- 자동 반영은 사용자별 고정 탭에만 수행한다. 실제 헤더는 `주차 | 월 | 화 | 수 | 목 | 금 | 차주 계획 | 이슈·요청`이며 주차당 한 행이다. 원본 팀 현황표에는 사용자가 직접 복사한다. 차주 계획은 다음 주만 의미한다. 이슈·요청은 의존성과 필요한 자료를 짧게 쓴다. 이전 승인 내용과 미배정 업무를 임의로 삭제하지 않는다.
- 확정한 기간·배치·완료일·시트 제외 항목을 반영한 최종 주차별 표를 저장 입력으로 삼는다. Google에는 티켓 키·링크를 빼고 로컬 원본에는 유지한다. 시트 서식은 [표기 규칙](sheet-rules.md)을 따른다.
