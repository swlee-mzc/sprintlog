# 주간 현황 시트 표기 규칙

`sprintlog notation` 이 이 규칙을 판정한다. 스킬과 LLM은 기호·취소선을 임의로 바꾸지 않는다. 사용자가 보고 일정을 명시해 확정한 경우 로컬 동기화 입력에 그 의미를 반영한다.

| 표기 | 조건 |
|---|---|
| `기능명` | 그날이 기능의 계획 기간(내 서브태스크 시작 날짜 중 가장 이른 날 ~ 기한 중 가장 늦은 날)에 들어감 |
| `[완료] 기능명` | 기능의 완료 예정일 = 내 서브태스크 기한 중 가장 늦은 날 |
| `[완료-지연(MMDD)] 기능명` | 원래 예정일 칸. 처음 기한(기한 이력의 가장 이른 값)보다 현재 기한이 늦을 때. MMDD 는 현재 기한 |
| 취소선 | 기능의 내 서브태스크가 모두 완료됨. 지연 여부와 상관없이 `[완료]`·`[완료-지연]` 줄에 적용 |
| 차주 계획 | 다음 주에 계획 기간이 걸친 기능. 다음 주에 끝나면 `[완료] 기능명` |
| 고정 문구 | 프로필 `fixedLines`. 완료 표기 없이 근무일마다 끝에 붙는다. 문자열은 모든 근무일, `{ "text", "from", "to" }` 는 그 기간의 근무일에만 붙고, 기간이 다음 주에 걸치면 차주 계획에도 들어간다 |

- 기능 = 내 서브태스크의 부모 티켓. 서브태스크 없이 내게 배정된 티켓은 그 자체가 기능이다.
- 완료는 기능 전체가 아니라 내 담당 서브태스크 기준이다.
- 취소된(DROP) 서브태스크는 제외한다.
- 휴일 칸은 쓰지 않는다. 사람이 적은 `휴가` 등은 그대로 둔다.
- 프로필 `jira.site` 가 있으면 줄 끝에 `(티켓 키)` 를 붙이고 그 키에 티켓 링크를 건다.
- 줄 앞에는 프로필 `sheet.bullet`(기본 `- `)을 붙인다.

- 실제 완료일이 있으면 완료 보고일로 사용한다. 토·일 완료는 직전 금요일에 보고하며 Jira의 실제 시각은 유지한다. 금요일 예정 작업의 주말 완료에는 지연을 붙이지 않는다.
- 시작·진행 줄은 완료·지연 태그와 취소선을 붙이지 않는다. 지연은 원래 완료 예정일에, 완료 예정은 변경 완료 예정일에 표시한다.
- `countScopes`에 기능별 집계 대상 티켓 목록을 확정해 저장하면 제목 옆에 누적 완료/전체 건수를 붙인다. 누락된 티켓이 있으면 집계를 중단하고 다시 수집한다. 범위 밖 기존 완료 티켓은 분모에서 제외한다.
- 기존 수동·보류·검토 중 줄은 대상에서 사라졌다는 이유만으로 지우지 않는다. 같은 티켓 또는 같은 문구의 줄만 최신 입력으로 대체한다.
- 미배정 목록은 로컬 Excel의 unscheduled 탭에만 보관한다. 이 목록을 날짜별 칸이나 Google 시트에 가져오지 않는다.
