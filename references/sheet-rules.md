# 주간 현황 시트 표기 규칙

`sprintlog notation` 이 이 규칙을 판정한다. 스킬과 LLM 은 결과를 바꾸지 않는다.

| 표기 | 조건 |
|---|---|
| `기능명` | 그날이 기능의 계획 기간(내 서브태스크 시작 날짜 중 가장 이른 날 ~ 기한 중 가장 늦은 날)에 들어감 |
| `[완료] 기능명` | 기능의 완료 예정일 = 내 서브태스크 기한 중 가장 늦은 날 |
| `[완료-지연(MMDD)] 기능명` | 원래 예정일 칸. 처음 기한(기한 이력의 가장 이른 값)보다 현재 기한이 늦을 때. MMDD 는 현재 기한 |
| 취소선 | 기능의 내 서브태스크가 모두 완료됨. 지연 여부와 상관없이 `[완료]`·`[완료-지연]` 줄에 적용 |
| 차주 계획 | 다음 주에 계획 기간이 걸친 기능. 다음 주에 끝나면 `[완료] 기능명` |
| 고정 문구 | 프로필 `fixedLines`. 근무일마다 끝에 붙는다 |

- 기능 = 내 서브태스크의 부모 티켓. 서브태스크 없이 내게 배정된 티켓은 그 자체가 기능이다.
- 완료는 기능 전체가 아니라 내 담당 서브태스크 기준이다.
- 취소된(DROP) 서브태스크는 제외한다.
- 휴일 칸은 비운다.
- 줄 앞에는 프로필 `sheet.bullet`(기본 `- `)을 붙인다.
